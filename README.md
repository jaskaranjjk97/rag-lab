# RAG Lab — Building Retrieval-Augmented Generation Systems

A hands-on engineering portfolio exploring how to design, build, evaluate, and improve Retrieval-Augmented Generation (RAG) systems using Python and modern GenAI technologies.

This repository contains practical RAG implementations, from foundational retrieval pipelines to advanced systems involving hybrid search, reranking, agentic workflows, and multimodal document understanding.

## Projects

| # | Project | Description | Status |
|---|---|---|---|
| 01 | [LinkedIn AI Icebreakers](./01-linkedin-ai-icebreakers/) | Extract LinkedIn profile information, generate interesting facts, and answer profile-based questions using RAG. | Completed |
| 02 | Vanilla RAG | Build a foundational PDF question-answering pipeline. | Planned |
| 03 | Hybrid RAG | Combine keyword and vector retrieval. | Planned |
| 04 | Reranking RAG | Improve retrieval relevance using cross-encoder reranking. | Planned |

## Technology Areas

- Python and LlamaIndex
- LangChain and LangGraph
- Embeddings and vector databases
- Semantic and keyword retrieval
- Hybrid search and Reciprocal Rank Fusion
- Cross-encoder reranking
- Retrieval evaluation
- Prompt engineering and LLM integration
- Agentic AI and tool calling
- Multimodal document processing

## Repository Philosophy

Each project focuses on:

1. Understanding the problem and system architecture.
2. Implementing the retrieval pipeline.
3. Keeping code understandable and maintainable.
4. Testing important functionality.
5. Evaluating retrieval and answer quality.
6. Documenting design decisions and limitations.

The goal is to demonstrate practical engineering knowledge rather than simply showcase framework usage.
